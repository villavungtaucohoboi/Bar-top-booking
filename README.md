# Bartop.vn – demo đặt bàn bar toàn quốc

Bản demo giao diện webapp đặt bàn bar, lounge, club khắp Việt Nam.

- Khung giờ vàng giảm thêm khi đặt sớm
- 3 giao diện Sáng / Nâu / Tối
- Ví điểm đổi tiền hoặc trừ bill
- Hạng thành viên, hội nhóm chat review, gói đẩy top cho chủ bar

Dữ liệu bar, số liệu và review là minh hoạ.
