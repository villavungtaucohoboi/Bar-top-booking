Kết nối tài khoản đăng bài

Dán khoá truy cập GitHub (chỉ làm một lần trên máy này).
  1. Mở trang tạo khoá GitHub.
  2. Token name: topchill-admin. Expiration: 1 năm.
  3. Repository access: Only select repositories → chọn .
  4. Mục Permissions: bấm + Add permissions → chọn Contents → đổi quyền thành Read and write.
  5. Bấm Generate token, copy rồi dán vào ô dưới.
